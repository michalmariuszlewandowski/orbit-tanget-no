\section{Experiments}
\label{sec:experiments}

\paragraph{Question.} We test whether local orbit consistency reduces symmetry-induced out-of-distribution error and equivariance defect for an unchanged neural-operator backbone. The main experiment uses a periodic \(64\times64\) 2D Navier--Stokes vorticity operator with Galilean boosts. The base model is the same FNO2d architecture in every row; orbit consistency changes training only and does not add an inference-time module.

\paragraph{Protocol.} We compare four methods: supervised FNO, supervised Lie augmentation, supervised orbit consistency, and augmentation plus orbit consistency. The headline low-label setting uses 2\% labeled data and five seeds. The compute-matched augmentation baseline uses six update steps per epoch, while augmentation plus orbit consistency uses four update steps per epoch with \(\lambda_{\mathrm{orb}}=0.10\). All reported rows use the same test-time model architecture and are regenerated by \texttt{python scripts/reproduce\_paper\_artifacts.py}.

\paragraph{Main N64 Galilean result.} Table~\ref{tab:n64-headline} shows that at 2\% labels, augmentation plus orbit consistency improves both paper-facing symmetry metrics over compute-matched supervised augmentation. Orbit OOD relative \(L^2\) decreases from \(0.5276\pm0.0525\) to \(0.3950\pm0.0334\), a 25.1\% reduction. Equivariance defect decreases from \(0.3816\pm0.0322\) to \(0.2677\pm0.0174\), a 29.8\% reduction. Relative to the plain supervised FNO baseline, the reductions are 58.7\% for orbit OOD error and 61.7\% for equivariance defect. Parameter counts are identical across the headline rows.

\paragraph{Compute accounting.} Table~\ref{tab:n64-compute} reports training compute for the same headline runs. The compute-matched augmentation baseline uses 900 optimizer steps and 1800 estimated model forward passes, while augmentation plus orbit consistency uses 600 optimizer steps and the same 1800 estimated model forward passes because each step evaluates the original, augmented, and orbit-transformed inputs. Inference latency remains within run-to-run noise because the deployed map is still the same FNO2d backbone.

\paragraph{Label efficiency.} Figure~\ref{fig:n64-label-efficiency} and Table~\ref{tab:n64-label-efficiency} show that the benefit persists across the low-label curve. Against compute-matched augmentation, \(\lambda_{\mathrm{orb}}=0.10\) reduces orbit OOD error by 13.7\%, 25.1\%, and 22.3\% at 1\%, 2\%, and 5\% labels respectively. The corresponding equivariance-defect reductions are 21.3\%, 29.8\%, and 33.2\%. This supports the label-efficiency framing: the orbit objective is most useful when supervision is scarce, while preserving the same inference map.

\paragraph{OOD severity.} Figure~\ref{fig:n64-ood-severity} and Table~\ref{tab:n64-severity-reductions} evaluate Galilean boosts from below the training radius to twice the training radius. The augmentation-plus-orbit model maintains a lower orbit OOD error at every tested boost. The relative OOD-error reductions are 26.4\%, 25.8\%, 25.3\%, 23.6\%, and 20.3\% at maximum boosts 0.10, 0.20, 0.25, 0.35, and 0.50. Equivariance-defect reductions follow the same trend, from 33.6\% at boost 0.10 to 23.6\% at boost 0.50.

\paragraph{Canonicalization calibration.} Table~\ref{tab:n64-privileged-calibration} reports a privileged relative-boost calibration, not a deployable analytic canonicalization baseline. In the OOD severity protocol, each test input \(a\) is paired with a sampled relative boost \(\delta\), producing \(T_\delta a\). The calibration uses this sampled \(\delta\) and the paired in-distribution prediction \(\mathcal G_\theta(a)\), then reports \(T_\delta \mathcal G_\theta(a)\). This is useful for measuring how much of the direct OOD error comes from motion along the tested orbit, but it assumes access to the paired source input and sampled relative transform. It should therefore not be confused with the observable-frame analytic baseline, which reads the absolute ambient velocity \(c\) from the input channels and canonicalizes a single test input. At maximum boost 0.50, augmentation plus orbit consistency has direct OOD error \(0.4910\pm0.0216\), improving substantially over augmentation \(0.6158\pm0.0384\) while remaining above its privileged calibration value \(0.3676\pm0.0360\).

\paragraph{Defect as predictor.} Figure~\ref{fig:n64-defect-correlation} and Table~\ref{tab:n64-defect-correlation} show that equivariance defect is not merely an auxiliary metric. Across 90 cached N64 Galilean observations, defect correlates strongly with orbit OOD relative \(L^2\) (Pearson \(r=0.851\), Spearman \(\rho=0.838\)); after residualizing source, method, label fraction, maximum boost, and \(\lambda_{\mathrm{orb}}\), the partial Pearson correlation remains \(r=0.779\). The relationship also holds within the OOD severity curve alone (\(r=0.761\)), supporting the mechanism that improved orbit consistency tracks improved OOD behavior.

\paragraph{Ablations and scope.} Table~\ref{tab:n64-lambda} reports the orbit-weight ablation at 2\% labels and supports the final \(\lambda_{\mathrm{orb}}=0.10\) setting. Semi-supervised joint orbit training is useful as an appendix result because it reduces equivariance defect, but it is not the strongest predictive-error result. We do not include a 3D PDE in the main study: a same-resolution 3D analogue would multiply raw field size by 64 and introduce a new solver and validation burden. The current contribution is deliberately narrow: exact-symmetry validation plus a reproducible 2D Galilean low-label result.
