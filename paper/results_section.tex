\section{Experiments}

\paragraph{Question.}
We test whether local orbit consistency reduces symmetry-induced
out-of-distribution error and equivariance defect for an unchanged neural
operator backbone. The main experiment uses a periodic \(64\times64\) 2D
Navier--Stokes vorticity operator with Galilean boosts. The base model is the
same FNO2d architecture in every row; orbit consistency changes training only
and does not add an inference-time module.

\paragraph{Protocol.}
We compare four methods: supervised FNO, supervised Lie augmentation,
supervised orbit consistency, and augmentation plus orbit consistency. The
headline low-label setting uses 2\% labeled data and five seeds. The
compute-matched augmentation baseline uses six update steps per epoch, while
augmentation plus orbit consistency uses four update steps per epoch with
\(\lambda_{\mathrm{orb}}=0.10\). All reported runs use the same dataset hash,
parameter count, and test-time model architecture. The cached reproduction
command is:
\[
\texttt{python scripts/reproduce\_paper\_artifacts.py}.
\]

\paragraph{Main N64 Galilean result.}
At 2\% labels, augmentation plus orbit consistency improves both paper-facing
symmetry metrics over compute-matched supervised augmentation. Orbit OOD
relative \(L^2\) decreases from \(0.5276\pm0.0525\) to
\(0.3950\pm0.0334\), a 25.1\% reduction. Equivariance defect decreases from
\(0.3816\pm0.0322\) to \(0.2677\pm0.0174\), a 29.8\% reduction. Relative to
the plain supervised FNO baseline, the reductions are 58.7\% for orbit OOD
error and 61.7\% for equivariance defect. Parameter counts are identical across
the headline rows.

\paragraph{Label efficiency.}
The benefit persists across the low-label curve. Against compute-matched
augmentation, \(\lambda_{\mathrm{orb}}=0.10\) reduces orbit OOD error by
13.7\%, 25.1\%, and 22.3\% at 1\%, 2\%, and 5\% labels respectively. The
corresponding equivariance-defect reductions are 21.3\%, 29.8\%, and 33.2\%.
This supports the label-efficiency framing: the orbit objective is most useful
when supervision is scarce, while preserving the same inference map.

\paragraph{OOD severity.}
At 2\% labels, the OOD severity curve evaluates Galilean boosts from below the
training radius to twice the training radius. The augmentation-plus-orbit model
maintains a lower orbit OOD error at every tested boost. The relative OOD-error
reductions are 26.4\%, 25.8\%, 25.3\%, 23.6\%, and 20.3\% at maximum boosts
0.10, 0.20, 0.25, 0.35, and 0.50. Equivariance-defect reductions follow the
same trend, from 33.6\% at boost 0.10 to 23.6\% at boost 0.50.

\paragraph{Ablations and scope.}
A small orbit-weight sweep at 2\% labels supports the final
\(\lambda_{\mathrm{orb}}=0.10\) setting: orbit OOD error decreases from 0.5768
at \(\lambda=0.01\) to 0.4518 at \(\lambda=0.05\) and 0.3950 at
\(\lambda=0.10\). Semi-supervised joint orbit training is useful as an appendix
result because it reduces equivariance defect, but it is not the strongest
predictive-error result. We do not include a 3D PDE in the main study: a
same-resolution 3D analogue would multiply raw field size by 64 and introduce a
new solver and validation burden. The current contribution is deliberately
narrow: exact-symmetry validation plus a reproducible 2D Galilean low-label
result.
