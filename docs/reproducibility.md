# Reproduction

Experiment definitions, seeds, and dataset checksums are in
`configs/release.yaml`.

## Regenerate figures from saved results

The saved per-seed CSV results regenerate the label-efficiency, severity, and
defect/error correlation plots without model checkpoints:

```bash
python scripts/verify_paper_results.py
python scripts/plot_galilean_n64_paper_figures.py
python scripts/make_paper_diagnostics.py --cached-compute
```

The qualitative fields, fixed-stress diagnostics, and equivariance residuals
use the two existing local seed-23 checkpoints at their original run paths in
`figure_specs/2d_galilean_n64_id_ood_seed23.yaml`, together with the Galilean N64
dataset. The spec records their SHA-256 values and checkpoint protocol. When
these inputs are present, regenerate all figures with:

```bash
python scripts/reproduce_release.py --suite main --stage figures --preflight
python scripts/reproduce_release.py --suite main --stage figures --execute
```

This produces the label-efficiency, severity, defect/error correlation,
qualitative fields, fixed-stress diagnostics, and equivariance-residual figures
as PNG/PDF files in `runs/figures/`. The field figures evaluate the saved local
models; the statistical plots use the archived per-seed CSVs. Preflight checks
the frozen input hashes before execution.

Compute diagnostics use archived CSV measurements during figure reproduction.
Historical wall times were measured using local RNG file timestamps, which Git
does not preserve. To compute diagnostics for new training runs, use
`python scripts/make_paper_diagnostics.py` with the new run logs present.

## Check results or rerun experiments

```bash
python scripts/verify_paper_results.py
python scripts/reproduce_release.py --dry-run
python scripts/reproduce_release.py --preflight
python scripts/reproduce_release.py --suite main --execute
```

The statistics check covers Tables 2, 3, 4, 11, 14, 15, and 16. References are
in `figure_specs/paper_results.yaml`; the command recomputes statistics from
per-seed records and checks seed sets, parameter counts, and hash fields.

Omit `--suite main` to run all suites; repeat `--suite` to select several.
The default `--stage experiments` runs data, training, evaluation, and reports.
Use `--stage data`, `train`, `evaluate`, or `reports` for one stage; use
`--stage figures` for frozen paper figure regeneration as described above.
`--stage all` includes both workflows and requires the historical figure inputs.
Newly trained checkpoints record new source and environment metadata, so their
file hashes differ from those in the frozen figure spec.
Dependencies are selected automatically; matching completed runs are reused.
Use a fresh checkout for retraining. Report commands write CSV files; TeX
sources and TeX table exports are excluded from the release.

## Data and checkpoints

The workflow reuses the bundled Galilean N64 dataset and generates missing
unboosted N64, Burgers N128, and Dirichlet heat datasets before training.
To generate only data, run:

```bash
python scripts/reproduce_release.py --stage data --execute
```

Reference dataset checksums are recorded in `configs/release.yaml`.
Checkpoint evaluation checks the dataset checksum saved with the model.

The rMD17 reference split is included in `data/rmd17/rmd17_ethanol_force_500.pt`.
Use this tensor to evaluate the same samples; its recorded `old_indices`
define the split. `scripts/verify_rmd17_cached_dataset.py` checks the tensor
against the raw NPZ using those indices and the raw-data hash.

Evaluate a checkpoint with its saved seed and orbit settings:

```bash
python scripts/evaluate.py --checkpoint PATH/checkpoints/best.pt --device cpu --out evaluation.json
```

Use `--dataset PATH` to relocate data; its saved SHA-256 must match. Keep the two
figure checkpoints at the existing local run paths named in the figure spec.
Other model checkpoints can be regenerated by training. Reports that recompute
experiments from raw run records require those training runs. Measure latency
on the target machine.

## Training and checkpoint records

Runs save the resolved config and hash, dataset SHA-256, source hashes,
environment, metrics, and RNG snapshots. `best.pt` is selected by validation
error; `last.pt` contains the final model and matching optimizer state.
The workflow sets OMP and MKL threads to one. Dependencies are pinned in
`uv.lock`; each run records its execution environment in `meta.json`.

Seeded retraining supports statistical comparisons. Use saved checkpoints
when a comparison requires identical model weights. Resuming training also
requires the saved optimizer and RNG state. Compare training times using
complete-run measurements.

## Reclaim checkpoint space after experiments

Preview final-training snapshots that can be removed from completed release runs:

```bash
python scripts/prune_release_checkpoints.py
python scripts/prune_release_checkpoints.py --execute
```

Run cleanup after training and evaluation jobs have stopped. The command selects
only `checkpoints/last.pt` from runs in `configs/release.yaml`, checks completed
training evidence and the snapshot's final epoch/results, and preserves any
checkpoint declared as a release dependency. It checks for changed files again
before deletion and writes a JSON audit under `runs/cleanup/`.

`best.pt`, adapted models, datasets, metrics, configs, RNG records, and figures
are retained. Removing `last.pt` discards the exact final-training resume state;
the retained `best.pt` continues to support paper evaluation and figures. Older
checkpoints that cannot prove completion are kept and reported. The default
command previews candidates without deleting them.

Check the retained release inputs and paper statistics after cleanup:

```bash
python scripts/reproduce_release.py --preflight
python scripts/verify_paper_results.py
```

### Retaining only the models needed for figure edits

For a local archive of completed results, the two seed-23 checkpoints named in
`figure_specs/2d_galilean_n64_id_ood_seed23.yaml` are sufficient to regenerate
the qualitative fields, fixed-stress diagnostics, and equivariance residuals.
Together they occupy about 122 MiB. Preserve their recorded SHA-256 values and
the Galilean dataset as well. The label-efficiency, severity, and correlation
plots use the saved CSVs. Preserve the archived compute CSVs as well; computing
new timing summaries requires training logs and RNG file timestamps.

Keep these two checkpoints at their existing local run paths. Experiment
checkpoints, run logs, RNG snapshots, generated figures, and deletion audits
remain excluded from Git. The Galilean figure dataset and rMD17 reference split
are included; other datasets can be regenerated.

To validate or regenerate figures from this reduced archive, run:

```bash
python scripts/reproduce_release.py --suite main --stage figures --preflight
python scripts/reproduce_release.py --suite main --stage figures --execute
python scripts/verify_paper_results.py
```

Full experiment preflight and `reproduce_paper_artifacts.py` require original
training evidence and will report pruned local runs as incomplete. To evaluate
those models again, retrain in a fresh checkout using the release registry.

See the [code guide](code-guide.md) for objective definitions, tensor conventions,
and configuration fields.
